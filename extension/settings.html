Your providers. Your keys.

Each stage uses only the provider you select. Usage and connection tests are billed to your provider account. No paid fallback.

Processing backend

Your keys, media/captions and text are sent to this backend when you start a job or test a connection. Only use a backend you trust. It holds keys in memory for processing, then discards them; restart requires resubmission.

Default: session-only keys, cleared when Chrome exits. Remembered keys use extension-local storage, which is not an encrypted secrets vault. Keys never sync.
